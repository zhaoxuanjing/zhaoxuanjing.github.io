# AI视频 Prompt 工程学：从提示词到视觉导演系统

随着 AI 视频模型的发展（即梦、Runway、Sora 等），**Prompt 正在成为一种新的视觉语言**。

在传统电影制作中，导演通过：

- 镜头
- 场景
- 光线
- 表演

来构建画面。

而在 AI 视频时代，这些内容需要通过 **Prompt（提示词）** 来表达。

因此，Prompt 不再只是简单描述，而是一种 **“AI导演语言”**。

本文将系统讲解 **AI视频 Prompt 工程学**：

1. Prompt结构
2. Prompt写作方法
3. Prompt词库
4. Prompt优化技巧
5. Prompt工业化生产方法

---

# 一、什么是 Prompt 工程学

Prompt 工程学（Prompt Engineering）是指：

> 通过结构化提示词控制 AI 生成结果。

对于 AI 视频来说，本质就是：

```
用语言描述一个电影镜头
```

优秀 Prompt 的核心目标：

```
控制画面
控制风格
控制叙事
```

---

# 二、影视级 Prompt 结构

专业 AI 视频 Prompt 通常遵循以下结构：

```
镜头
↓
主体
↓
细节
↓
动作
↓
剧情
↓
环境
↓
光影
↓
风格
```

完整公式：

```
Prompt =
镜头
+ 主体
+ 细节
+ 动作
+ 剧情
+ 环境
+ 光影
+ 风格
```

# 三、Prompt 写作方法

## 1 镜头语言

镜头决定画面的视觉表现。

常见镜头：

```
特写镜头
中景镜头
广角镜头
长焦镜头
航拍镜头
跟随镜头
手持镜头
```

示例：

```
电影级画面
4K超清
长焦特写镜头
浅景深
```

---

## 2 主体角色

结构：

```
年龄 + 种族 + 身份
```

示例：

```
年轻的东亚女剑客
未来城市机械工程师
中世纪骑士
```

---

## 3 细节描述

细节是画面质量的关键。

推荐描述：

```
头发
服装
材质
表面状态
```

示例：

```
被雪水打湿的黑发
粗布武士服
布料磨损
表面有湿痕
```

---

## 4 动作设计

动作让画面更生动。

示例：

```
左臂平伸
身体前倾
缓慢转身
```

---

## 5 剧情信息

加入剧情可以增强画面故事性。

示例：

```
在她身后
被击败的敌人
踉跄后退
```

---

## 6 场景环境

场景决定世界观。

示例：

```
冰封荒原
未来城市
沙漠废墟
古代城镇
```

---

## 7 光影设计

光影是电影感的核心。

示例：

```
柔和散射光
逆光
晨雾光线
夕阳光
```

---

## 8 风格参考

风格控制画面美术。

示例：

```
武侠电影风格
赛博朋克风格
黑泽明电影风格
宫崎骏动画风格
```

# 七、Prompt 批量生产方法

AI短视频创作者通常需要大量 Prompt。

可以使用模板方法：

```
镜头模板
+
角色模板
+
场景模板
+
风格模板
```

示例：

```
电影级4K画面
长焦特写镜头

一位【角色】

站在【场景】

天气【天气】

光线【光影】

风格类似【导演】
```

变量替换：

```
角色
场景
天气
导演
```

即可批量生成 Prompt。
